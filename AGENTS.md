# Repository instructions

- Work on `main` unless the user explicitly requests another branch.
- Use English for documentation, comments, docstrings, messages, commits, issues,
  and release notes.
- Keep user-facing SDK documentation here and contributor test guidance in
  `tests/README.md`.
- Record review decisions, commit references, and validation results on the
  related GitHub issue.
- Do not add internal development notes, investigation records, or audit diaries
  to this public SDK repository. Store them in the private
  `deepxfinance/notes-and-specs` repository.
